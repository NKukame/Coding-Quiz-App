# 🧠 Dynamic Quiz App

A customizable quiz application built with **React** that allows users to select their preferred language, question type, number of questions, and time limit before starting the quiz.

---

## ✨ Features

- ✅ Supports **Multiple-Choice** and **True-or-False** questions
- 🗃️ Filters questions based on selected **language** and **type**
- ⏱️ Custom **timer** based on user’s input
- 📊 Displays score and quiz results at the end
- ⚠️ Toast notifications for validation (e.g., when no option is selected)
- 📈 Visual **progress bar**

---

## 📁 JSON Question Format

Questions are stored in a JSON format by language and type.
